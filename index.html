Random Forest · Classification 🥇 #1

NYC Housing Land Use — Building Age Prediction

Predicts whether a NYC property is over or under 100 years old using 14 housing features including sale price, lot area, zip code, and floor count. A Random Forest of 14 decision trees achieved 99% accuracy — with year built and block number as the most decisive factors.

Kaggle Dataset14 Features99% Accuracy Feature ImportanceDecision Tree Ensemble
View on GitHub — Random_Tree_Forest_IS170.ipynb
Key Visualizations
Feature importance ranking
Decision Tree vs Random Forest accuracy
Project Summary

My partner and I decided to use this NYC housing dataset for one of our random forests. We wanted to see the outcome of whether a house is over or less than 100 years old. This algorithm will create multiple decision trees where it creates different classes to determine a certain outcome. The random forest grabs "random" trees to test out the accuracy of variables we have chosen while including the outcome. These variables consisted of house stats, including the lot number, zip code, sale price, etc. We decided to choose the house age as the target outcome and achieved 99% accuracy — meaning we have enough and accurate information to determine the age of the house. We also used precision, recall, and F1 score which determines how true the data is to itself. A good note for this algorithm is that it randomly chooses the decision trees and leaves the rest — meaning whatever is not chosen will not be used to determine the accuracy of the target outcome.

K-Nearest Neighbors · Classification 🥈 #2

Cancer Diagnosis from Gene Expression

Predicts cancer presence from genomic data using K-Nearest Neighbors. Uses cross-validation to find the optimal K value, producing a confusion matrix and full classification report. At K=20, the model peaks at 94.7% accuracy on 600 patient records.

Kaggle DatasetCross-Validation Genomic DataConfusion Matrix94.7% Accuracy
View on GitHub — K_Nearest_Neighbors.ipynb
Key Visualizations
Confusion matrix — cancer diagnosis
Accuracy vs K — finding the optimal neighbor count
Gene One vs Gene Two — cancer class separation
Project Summary

The dataset we decided to use is a cancer dataset with gene expressions that indicate whether a patient has cancer or not. There are only two genes, and based on the gene values, the algorithm determines if cancer is present. We used K-Nearest Neighbors, which trains on the current data and ensures 93% usability, while detecting true or false positives. We test and train the model by calculating the mean of each gene grouped by cancer class. The algorithm calculates the Euclidean distance from all samples and finds the 5 closest neighbors, taking a majority vote. We charted the data multiple times to verify usability, and at the end built a predictive model where you input values for Gene One and Gene Two. Those values return probability percentages — in our final test case, there was a 70% chance cancer was present and a 30% chance it was not.

XGBoost · Gradient Boosting Regression 🥉 #3

Insurance Charge Prediction

Uses XGBoost — the most advanced and industry-standard algorithm in this collection — to predict health insurance premiums from customer demographics. Pulls 50 random data subsets to build an efficient ensemble that outperforms a single decision tree, evaluated with MAE, RMSE, and R².

XGBoostEnsemble Learning MAE / RMSE / R²Feature ImportanceRegression
View on GitHub — XBM_Gradient_Regression (1).ipynb
Key Visualizations
Actual vs. predicted charges — points along the diagonal indicate accurate predictions
Project Summary

My partner and I decided to focus on insurance statistics from a set of customers. This dataset was perfect for trying to predict insurance charges based on customer profiles and their actual charges. This algorithm uses an XGBoost prediction model, which implements a gradient boosting strategy to improve prediction accuracy by sequentially correcting the errors of previous trees. We trained and tested the dataset using this ensemble approach. To make it faster and more efficient, the algorithm samples 50 random subsets of the dataset to build smaller, specialized predictors. We applied this to the entire dataset and created a scatter plot to compare the predicted and actual insurance charges — points clustering along the diagonal indicate strong predictive accuracy across the full cost range.
